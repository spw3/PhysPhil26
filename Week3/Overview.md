Quiz:
1. At what value of r does the first period-doubling bifurcation occur?
 (a) r = 2 (b) r = 3 (c) r = 3.57 (d) r = 4
2. What does a positive Lyapunov exponent indicate?
 (a) Stable fixed point (b) Period-2 orbit (c) Chaotic behavior (d) Extinction
3. What is the Feigenbaum constant δ approximately equal to?
 (a) 3.14159 (b) 2.71828 (c) 4.66920 (d) 1.61803
4. For r = 3.83, what kind of orbit exists?
 (a) Period-1 (b) Period-2 (c) Period-3 (d) No orbit (diverges)
5. The logistic map x_{n+1} = rx_n(1-x_n) maps [0,1] to [0,1] only when:
 (a) 0 ≤ r ≤ 2 (b) 0 ≤ r ≤ 4 (c) 0 ≤ r ≤ 3 (d) r > 4
6. What happens to the logistic map when r < 1?
 (a) Period doubling (b) Chaos (c) x converges to 0 (extinction) (d) x converges to 1
